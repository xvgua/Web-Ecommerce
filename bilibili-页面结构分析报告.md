# Bilibili 首页页面结构分析报告

> 分析对象：`哔哩哔哩 (゜-゜)つロ 干杯~-bilibili.html`（B 站首页完整快照）
> 配套样式：`哔哩哔哩 (゜-゜)つロ 干杯~-bilibili_files/index-3c8c71be.css`

## 一、页面总体架构

B 站首页采用**三层级垂直布局**，自上而下依次为：

```
┌──────────────────────────────────────────────┐
│  顶部导航栏 (.bili-header)                     │
│  ├── 顶栏 (.bili-header__bar)                 │
│  ├── Banner 区 (.bili-header__banner)          │
│  └── 频道导航栏 (.bili-header__channel)        │
├──────────────────────────────────────────────┤
│  主内容区 (.bili-feed4)                        │
│  ├── 推荐横幅轮播 (.recommended-swipe)          │
│  ├── 双栏内容 (.recommended-container_floor-aside)│
│  │   ├── 左侧主内容流（视频卡片流）              │
│  │   └── 右侧边栏                             │
│  └── 更多内容楼层（漫画/赛事/游戏等）            │
├──────────────────────────────────────────────┤
│  推广/下载区 (.download-wrapper)                │
├──────────────────────────────────────────────┤
│  浮动按钮 (.palette-button-wrap)                │
└──────────────────────────────────────────────┘
```

## 二、设计系统特征

### 2.1 颜色体系

B 站采用**语义化 Design Token 系统**，所有颜色通过 CSS 变量定义，形成三层抽象架构：

| 层级           | 作用               | 示例                                                          |
| -------------- | ------------------ | ------------------------------------------------------------- |
| **原始色板**   | 基础色相+明度阶梯  | `--Pi5`（品牌粉）、`--Ga7`（灰色第7阶）、`--Lb5`（蓝色第5阶） |
| **语义 Token** | 按功能用途命名     | `--brand_pink`、`--text1`、`--bg1`、`--line_regular`          |
| **RGB 变体**   | 供 rgba() 组合使用 | `--brand_pink_rgb`、`--text1_rgb`                             |

#### 色板体系表

| 色系               | 前缀               | 语义映射                                        | 用途                             |
| ------------------ | ------------------ | ----------------------------------------------- | -------------------------------- |
| Pink（粉）         | `--Pi*`            | `--brand_pink`                                  | 品牌主色                         |
| Light Blue（浅蓝） | `--Lb*`            | `--brand_blue`                                  | 品牌辅色、链接色                 |
| Red（红）          | `--Re*`            | `--stress_red`                                  | 强调/错误                        |
| Green（绿）        | `--Gr*`            | `--success_green`                               | 成功状态                         |
| Orange（橙）       | `--Or*`            | `--operate_orange`                              | 操作提示                         |
| Yellow（黄）       | `--Ye*`            | `--pay_yellow`                                  | 支付/通知                        |
| Cyan（青）         | `--Cy*`            | —                                               | 信息提示辅助色                   |
| Magenta（品红）    | `--Ma*`            | —                                               | 辅助色                           |
| Brown（棕褐）      | `--Br*`            | —                                               | 辅助色                           |
| Silver（银灰）     | `--Si*`            | —                                               | 科技感辅助色                     |
| Gray（灰）         | `--Ga0` ~ `--Ga13` | `--text1~4`、`--bg1~3`、`--line_*`、`--graph_*` | 中性色（文字、背景、线条、图标） |
| White（白）        | `--Wh*`            | `--bg1`、`--graph_white`                        | 白色背景/图形                    |
| Black（黑）        | `--Ba*`            | `--shadow`                                      | 阴影/蒙层                        |

> 注：每色系从 0 阶（最浅）到 10 阶（最深），共 11 级色阶。共 10 个色系 × 11 级 = 110+ 基础色值，均配备对应 RGB 变量（如 `--Pi5_rgb`）用于 rgba() 透明度组合。

#### 核心语义色值映射

```
--brand_pink    ← --Pi5      （品牌粉）
--brand_blue    ← --Lb5      （品牌蓝）
--text1         ← --Ga10     （主文字，最深灰）
--text2         ← --Ga7      （次文字）
--text3         ← --Ga5      （辅助文字）
--text4         ← --Ga3      （最浅文字）
--bg1           ← --Wh0      （主背景，纯白）
--bg2           ← --Ga0      （次背景）
--bg3           ← --Ga1      （三级背景）
--line_light    ← --Ga1_s    （细线）
--line_regular  ← --Ga2      （常规线）
--line_bold     ← --Ga3      （粗线）
```

#### 关键色彩特点

- **浅色主题**：默认白底（`--bg1: var(--Wh0)`），文字用灰度层级区分信息重要性
- **品牌色克制使用**：仅关键交互元素使用品牌粉/蓝，大面积保持灰色调
- **hover 态统一**：几乎所有可交互元素 hover 时背景变为 `--graph_bg_thick`
- **透明度渐变**：Banner 顶部用 `linear-gradient(rgba(0,0,0,.4), transparent)` 叠加，增强文字可读性
- **暗色模式预备**：存在 `--v_brand_pink_hover`、`--v_brand_pink_active` 等带状态后缀的变量，搭配 `var(--brand_pink_hover, fallback)` 模式，为暗色主题切换预留了完整的变量覆盖机制

### 2.2 字体系统

| 属性            | 桌面端                                                                                                                            | 说明                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |

### 2.5 响应式设计

B 站首页的响应式策略是**以桌面端为核心的多级弹性适配**，不采用手机端的断点折叠模式。

**5 级断点体系：**

| 断点          | 定位       | 主要调整                                  |
| ------------- | ---------- | ----------------------------------------- |
| ≤1099.9px     | 小屏笔记本 | 56px 内边距，频道9列，字号12px            |
| 1100~1366.9px | 标准笔记本 | 56px 内边距，频道9列，图标40px            |
| 1367~1700.9px | 大屏笔记本 | 64px 内边距，频道11列，图标46px，字号14px |
| 1701~2199.9px | 宽屏桌面   | 96px 内边距，频道12列，字号14px           |
| ≥2200px       | 超宽屏     | max-width 2078px 锁定，频道14列，字号15px |

**响应式核心逻辑**：

- 不使用 `display: none` 隐藏内容
- 通过 **CSS Grid 列数变化**（`grid-template-columns: repeat(N, 1fr)`）增加内容密度
- 图标尺寸从 40px → 46px 递增
- 字体从 12px → 15px 递增
- 左右间距从 56px → 96px 递增，超宽屏居中锁定

## 三、页面分区详解

### 3.1 顶部导航栏（`.bili-header.large-header`）

这是 B 站最复杂的页面区域，包含三层子结构。

#### 第一层 — 顶栏（`.bili-header__bar`）

```
┌────────────────────────────────────────────────────────────┐
│ [左侧入口]  [────── 居中搜索栏 ──────]  [头像|上传|VIP|通知] │
└────────────────────────────────────────────────────────────┘
```

| 子区域       | 核心 Class                                      | 功能描述                                                                                                           |
| ------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 左侧入口弹出 | `.left-entry-popover`                           | 主导航菜单的弹出面板入口                                                                                           |
| 居中搜索栏   | `.center-search-container.offset-center-search` | 搜索输入框，带边框搜索条，内含 `.nav-search-input`、`.nav-search-btn`（搜索按钮）、`.nav-search-clean`（清除按钮） |
| 搜索面板     | `.search-panel`                                 | 搜索建议/历史下拉面板                                                                                              |
| 用户头像     | `.header-avatar-wrap`                           | 头像弹出菜单（个人中心入口）                                                                                       |
| 上传按钮     | `.header-upload-entry`                          | 带图标+文字的上传入口                                                                                              |
| VIP 入口     | `.right-entry--vip`                             | 大会员入口                                                                                                         |
| 消息/动态    | `.red-num--message` / `.red-num--dynamic`       | 红色角标通知                                                                                                       |

**搜索栏设计特色**：

- 输入框使用 `var(--graph_bg_regular)` 背景 + `opacity: 0.9`，聚焦时切换为 `--graph_bg_thick`
- 按钮 hover 时背景加深，统一使用 `transition: background-color .3s`

#### 第二层 — Banner 区（`.bili-header__banner`）

```
┌────────────────────────────────────────────────────────────┐
│  ░░░░░░░░░░ 渐变遮罩层 (taper-line) ░░░░░░░░░░░░░░░░░░░░  │
│                                                            │
│              [Banner 轮播背景图 / 动画层]                    │
│                                                            │
│  [Logo 图标]                      [浮动标题（hover显示）]    │
│  ───────────────── 可点击链接覆盖全区域 ─────────────────   │
└────────────────────────────────────────────────────────────┘
```

| 子元素   | Class                        | 说明                                                                    |
| -------- | ---------------------------- | ----------------------------------------------------------------------- |
| 容器     | `.bili-header__banner`       | `height: 9.375vw`（弹性高度），`min-height: 155px`，`max-height: 240px` |
| 动画层   | `.animated-banner > .layer`  | 多层叠层动画背景，flex 居中                                             |
| 内部容器 | `.header-banner__inner`      | `max-width: 2078px`，`display: flex; align-items: flex-end`             |
| Logo     | `.inner-logo` / `.head-logo` | 底部对齐的 Logo 图片                                                    |
| 渐变遮罩 | `.taper-line`                | 顶部 100px 黑色到透明渐变                                               |
| 浮动标题 | `.head-title`                | 初始 `opacity: 0`，hover 时显示，半透明黑底白字                         |
| 链接     | `.banner-link`               | 绝对定位覆盖全区域的可点击链接                                          |

**Banner 设计特色**：

- 弹性高度 `9.375vw` 使 Banner 随屏幕宽度自适应
- 多层动画背景叠加，配合绝对定位图片
- 渐变遮罩确保顶部导航文字可读性
- 标题采用延迟显示（hover 触发 `opacity` 过渡）

#### 第三层 — 频道导航栏（`.bili-header__channel`）

```
┌────────────────────────────────────────────────────────────┐
│  [🔥热门] [📢动态] │ [频道1] [频道2] ... [频道N] │ [更多→]  │
│  ─── 快速入口 ───  │ ──────── CSS Grid 频道区 ─────── │      │
└────────────────────────────────────────────────────────────┘
```

| 子区域       | Class                   | 说明                                                         |
| ------------ | ----------------------- | ------------------------------------------------------------ |
| 快速入口图标 | `.channel-icons`        | 热门/动态两个圆形图标入口，图标 40~46px，hover 变色          |
| 频道链接区   | `.channel-items__left`  | CSS Grid 布局，9~14 列自适应，每个频道为独立 `.channel-link` |
| 更多入口     | `.channel-items__right` | "更多"链接 + 箭头                                            |
| 固定定位     | `.header-channel-fixed` | 滚动时固定在顶部的频道栏副本                                 |

**频道 Grid 列数响应式**：

| 视口          | Grid 列数         |
| ------------- | ----------------- |
| ≤1366.9px     | `repeat(9, 1fr)`  |
| 1367~1700.9px | `repeat(11, 1fr)` |
| 1701~2199.9px | `repeat(12, 1fr)` |
| ≥2200px       | `repeat(14, 1fr)` |

**频道链接设计**：每个频道为独立卡片，`border: 1px solid var(--line_light)`，`border-radius: 6px`，hover 时背景和文字颜色加深。

### 3.2 主内容区（`.bili-feed4` > `.bili-feed4-layout` > `.container.is-version8`）

主内容区是 B 站首页的核心，采用**楼层式组织 + 双栏布局**的结构。

#### 整体架构

```
┌────────────────────────────────────────────────────┐
│  推荐横幅轮播 (.recommended-swipe)                    │
│  ┌──────────────────────────────────────────────┐  │
│  │  大图轮播（带footer标题和分页指示器）          │  │
│  └──────────────────────────────────────────────┘  │
├───────────────────────┬────────────────────────────┤
│  左侧：主内容流        │  右侧：边栏                 │
│  (.bili-feed-card × N) │  (.recommended-container   │
│                        │   _floor-aside)            │
│  ┌──────────────────┐ │  ┌──────────────────────┐  │
│  │  视频卡片 1       │ │  │  广告/推荐/下载       │  │
│  ├──────────────────┤ │  │  公告/排行榜           │  │
│  │  视频卡片 2       │ │  └──────────────────────┘  │
│  ├──────────────────┤ │                            │
│  │  ...无限滚动...   │ │                            │
│  └──────────────────┘ │                            │
├───────────────────────┴────────────────────────────┤
│  更多楼层：漫画区 / 赛事区 / 游戏区 / ...             │
└────────────────────────────────────────────────────┘
```

#### 3.2.1 推荐横幅轮播（`.recommended-swipe`）

位于内容区最顶部，展示推荐/广告内容的大图轮播。

| 子元素   | Class                            | 说明         |
| -------- | -------------------------------- | ------------ |

| 核心     | `.recommended-swipe-core`        | 轮播核心区域 |

#### 3.2.2 视频卡片（`.bili-video-card`）

B 站最核心的内容单元，每个视频为一个独立卡片。

```
┌──────────────────┐
```

#### 3.2.3 直播卡片（`.bili-live-card`）

| 子元素   | Class                           | 说明           |

#### 3.2.4 楼层系统（Floor System）

B 站将不同类型内容组织为"楼层"（Floor），每层有统一的标题+卡片结构：

| 楼层类型   | Key Class                                | 内容           |
| ---------- | ---------------------------------------- | -------------- |
| 单卡片楼层 | `.floor-card.single-card`                | 单个大卡片展示 |
| 楼层标题   | `.floor-title`                           | 楼层标题栏     |
| 楼层内部   | `.floor-card-inner`                      | 楼层内容容器   |
| 骨架楼层   | `.floor-card.single-card.floor-skeleton` | 楼层加载态     |
| 单一卡片   | `.floor-single-card`                     | 简化单卡       |

**已识别的具体楼层：**

| 楼层名称 | 对应 Class            | 功能描述                                   |
| -------- | --------------------- | ------------------------------------------ |
| 轮播区   | `.carousel-container` | 图片/内容轮播，带底部标题和分页点          |

## 四、页面构成特色总结

### 4.1 架构特色

1. **三层级 Header**：B 站的 Header 不是传统的单行导航，而是顶栏 → Banner → 频道导航三层级联结构，功能逐层递进（搜索/用户 → 品牌展示 → 内容导航）

2. **楼层式内容组织**：采用"楼层"（Floor）的概念组织多类型内容，每层独立、可插拔，支持运营灵活配置

3. **无限滚动 + 分楼层**：主视频流采用无限滚动（`.load-more-anchor` 触底加载），同时穿插独立楼层（漫画、赛事等），打破单一信息流的单调感

4. **双栏非对称布局**：左侧主内容流 + 右侧边栏的经典布局，但右侧边栏仅在特定楼层出现，不是全局固定

### 4.2 组件设计特色

1. **统一的卡片系统**：视频卡、直播卡、楼层卡共享相似的 BEM 命名结构（`__wrap`、`__info`、`__stats`、`__skeleton`），组件化程度高

2. **骨架屏全面覆盖**：每种内容卡片都有对应的 `skeleton` 组件，加载体验一致

3. **反馈机制内嵌**：视频卡和直播卡内置"不感兴趣"（`no-interest`）反馈面板，允许用户调教推荐算法

4. **Avatar 组件抽象**：头像组件（`.bili-avatar`）支持 8 种预设尺寸（24/30/36/40/48/50/60/80px）+ NFT 特殊样式，高度复用

### 4.3 交互设计特色

1. **弹性布局优先**：Banner 高度使用 `vw` 单位（`9.375vw`），内容区域通过 5 级断点渐近适配，而非传统的 3 断点手机/平板/桌面

2. **hover 即反馈**：几乎所有可交互元素都有 hover 态背景变化，使用 `--graph_bg_thick` 统一色值，过渡时间 0.2~0.3s

3. **渐进式内容展示**：Banner 标题初始隐藏，hover 时显示 → 降低视觉干扰，鼓励探索

4. **CSS Grid 动态列数**：频道导航使用 Grid 列数随视口变化的策略，在更多空间展示更多频道入口

### 4.4 设计 Token 特色

1. **三层抽象色彩体系**：原始色板 → 语义 Token → RGB 变体，支持主题切换（浅色/深色）

2. **灰度层级丰富**：Gray 色系从 `Ga0` 到 `Ga13` 共 14 个层级，细粒度控制文字、背景、线条、图标的灰度差异

3. **品牌色克制使用**：仅在关键交互处（VIP 按钮、收藏图标、品牌标识）使用品牌粉/蓝，大面积保持中性灰

### 4.5 命名规范

B 站采用 **BEM + 语义化前缀** 的命名体系：

| 前缀/模式         | 含义               | 示例                                               |
| ----------------- | ------------------ | -------------------------------------------------- |
| `.bili-*`         | 全局通用组件       | `.bili-header`、`.bili-video-card`、`.bili-avatar` |
| `.bili-*-layout`  | 布局容器           | `.bili-feed4-layout`                               |
| `__`              | BEM 子元素         | `.bili-video-card__wrap`                           |
| `--`              | BEM 修饰符         | `.bili-avatar-size-48`                             |
| `is-*`            | 状态类             | `.is-version8`、`.is-active`、`.is-rcmd`           |
| `has-*`           | 拥有状态           | `.has-*`                                           |
| `.v-*` / `.vui_*` | Vue 组件/UI 库组件 | `.v-img`、`.vui_carousel`                          |
| `.palette-*`      | 主题相关           | `.palette-button-wrap`                             |
| `.header-*`       | Header 专属子组件  | `.header-upload-entry`                             |
| `.channel-*`      | 频道导航专属       | `.channel-link`                                    |

## 五、技术架构特征

B 站首页的 HTML 文件虽然长达 4645 行，但实际 body 内容仅约 200 行（位于文件末尾），约 90% 的内容是播放器/弹幕系统在 `<head>` 中动态注入的内联样式（`data-injector="danmaku-x"`、`data-injector="nano"`）。

**核心技术栈识别**：

| 技术                | 识别依据                                                 |
| ------------------- | -------------------------------------------------------- |
| Vue 3               | SSR 注释标记 `<!--[-->...<!--]-->`、组件挂载模式         |
| Vite                | `window.__vite_is_modern_browser`、`import.meta.url`     |
| 服务端渲染（SSR）   | `<meta name="server_render" content="is_server_render">` |
| Vue Custom Carousel | `.vui_carousel` 组件命名                                 |
| 自研 UI 组件库      | `.v-popover`、`.v-img`、`.vui_*` 命名空间                |
| A/B 实验框架        | `window.abtest` 包含多个实验分组                         |

**性能策略**：

- 图片全面使用 `<picture>` + `<source>` 提供 AVIF/WEBP 回退
- 自定义性能埋点：白屏检测（`MirrorErrorFilterPlugin`）、首屏渲染（`fsrCb`）、首张轮播加载（`firstSwipeLoaded`）
- 骨架屏覆盖所有卡片类型（视频卡、直播卡、楼层卡）
- SPA 懒加载 + 无限滚动加载更多

**弹幕播放器**：页面内联了完整的弹幕系统（`.bili-danmaku-x`），支持滚动弹幕、顶部弹幕、底部弹幕、高级弹幕、PK 弹幕等多种类型。
