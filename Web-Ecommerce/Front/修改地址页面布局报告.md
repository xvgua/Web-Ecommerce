## 区域说明

### 1. 页面标题
- `font-size: 22px; font-weight: 700; margin-bottom: 20px;`
- "修改地址"，与"我的订单"标题样式一致

### 2. 当前收货地址（section 卡片）
- 白色背景，`border-radius: 12px; padding: 24px;`
- 标题："当前收货地址"
- 三行地址展示，样式与收货地址列表卡片一致
- 数据来源：`GET /orders/:id` 返回的 `order.address`

### 3. 选择其他地址（section 卡片）
- 标题栏：左侧"选择其他地址"，右侧 [+ 新增地址] 按钮
- 地址卡片列表，每项右侧带"选择"按钮：
  - 左侧：三行地址信息（省市区 / 详细地址 / 姓名 电话）
  - 右侧：`[选择]` 按钮
  - 样式与收货地址列表卡片一致
  - 排除当前正在使用的地址（`address.id === order.addressId`）
- 点击"选择" → `ElMessageBox.confirm` 二次确认 → `PUT /orders/:id/address` → 成功 toast → 返回订单详情
- 数据来源：`GET /user/addresses`
- "新增地址"点击弹出对话框（复用 address.vue 中的 dialog 逻辑）

## 交互流程

```
订单详情 → 点击"修改地址"
  → 进入 /orders/:id/edit-address
  → 页面加载：GET /orders/:id + GET /user/addresses
  → 用户点击某地址右侧的"选择"
    → ElMessageBox.confirm("确定使用该地址作为收货地址吗？")
    → 确认：PUT /orders/:id/address { addressId }
    → 后端校验：若已修改过（addressModified=1）→ 返回错误"您已经修改过地址啦"
    → 成功 → ElMessage.success("地址修改成功") → router.back()
  → 用户点击"新增地址"
    → 弹出 el-dialog → 保存
    → 刷新地址列表
```

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/orders/:id` | 获取订单（含当前地址） |
| GET | `/user/addresses` | 获取用户全部地址 |
| POST | `/user/addresses` | 新增地址 |
| PUT | `/orders/:id/address` | **新增** — 修改订单收货地址，body: `{ addressId }` |

## 组件

新建文件 `Web-Ecommerce/Front/client/src/views/order/edit-address.vue`

- Composition API (`<script setup lang="ts">`)
- 地址卡片样式与 `address.vue` 保持一致
- dialog 逻辑从 `address.vue` 抽取或复用

## 约束

- **仅可修改一次**：订单 `address_modified` 字段标记是否已修改过地址
  - 未修改时 → "修改地址"按钮可点击，跳转编辑页
  - 已修改后 → 按钮置灰显示"已修改过地址"，不可再点击
  - 后端 `PUT /orders/:id/address` 二次校验，已修改则返回 `"您已经修改过地址啦"`
