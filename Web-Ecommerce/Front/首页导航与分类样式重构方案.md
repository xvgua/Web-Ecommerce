## 三、具体变更方案

### 3.1 DefaultLayout.vue — 顶部导航栏重构

#### 结构变更：单行 → 双行

**现状（单行 60px）：**
```
┌─── Logo ─── Nav链接 ─── 搜索框(max480px) ─── 用户操作 ───┐  ← 60px
```

**计划（双行，主栏 64px + 分类栏 44px）：**
```
┌─── Logo ─── Nav链接 ─── 居中搜索框(flex:1) ─── 用户操作 ───┐  ← 64px（主顶栏）
├─── 🔥热门 ⭐新品 │ [分类1] [分类2] [分类3] ... [分类N] ────┤  ← 44px（分类导航栏）
```

#### 3.1.1 主顶栏（`.header__bar`）

| 变更点 | 说明 |
|--------|------|
| 高度 | 60px → 64px（对齐 `--v_height_xl`） |
| 搜索栏定位 | 从左侧 flex 流 → 三区对称居中（两侧 `flex: 1` 等宽，搜索栏 `flex: 0 0 560px`） |
| 搜索栏样式 | 保持圆角药片形状，增强 focus 态：多层 box-shadow 光晕 + 背景色过渡 |
| 背景 | 纯白 → 毛玻璃（`background: #fff; background: rgba(255,255,255,0.92); backdrop-filter: blur(12px)`，降级为纯白） |
| Logo | 字号 20px → 22px，增加字间距 |

**三区对称居中布局（替代 `margin: auto` 方案）：**

主顶栏使用 flex 三区布局，两侧等宽保证搜索栏视觉居中：

```scss
.header__bar-inner {
  display: flex;
  align-items: center;
  height: 64px;

  .header__bar-left  { flex: 1; display: flex; align-items: center; gap: 20px; }  // Logo + Nav
  .header__bar-search { flex: 0 0 560px; }                                         // 搜索栏，固定宽度
  .header__bar-right { flex: 1; display: flex; align-items: center; justify-content: flex-end; gap: 10px; } // 用户区
}
```

> 注意：`flex: 0 0` 和 `flex: 1` 是简写属性。该布局方案相比 `margin: auto` 在 flex 容器中更可靠，确保搜索栏严格居中而不受两侧内容长度影响。

**搜索栏 focus 态过渡（参考 B 站的 input 多层背景变化）：**

```
默认态:  border-color: var(--line-regular); background: var(--bg2); box-shadow: none;
hover态: border-color: var(--brand-primary-hover); background: #ecf5ff; box-shadow: 0 2px 8px rgba(var(--brand-primary-rgb), 0.08);
focus态: border-color: var(--brand-primary); background: #fff; box-shadow: 0 4px 16px rgba(var(--brand-primary-rgb), 0.15);
```

#### 3.1.2 分类导航栏（`.header__channel` — 新增）

这是本次重构的核心新增区域，直接参考 B 站 `.bili-header__channel` 的设计。

**HTML 结构草图：**
```html
<nav class="header__channel">
  <div class="header__channel-inner">
    <!-- 快速入口（参考 B 站 channel-icons） -->
    <div class="channel__quick">
      <router-link to="/products?sort=sales_desc" class="channel__quick-item">
        <span class="channel__quick-icon">🔥</span>
        <span>热门</span>
      </router-link>
      <router-link to="/products?sort=newest" class="channel__quick-item">
        <span class="channel__quick-icon">✨</span>
        <span>新品</span>
      </router-link>
    </div>

    <!-- 分类 pill 网格（参考 B 站 channel-items__left） -->
    <div class="channel__items">
      <router-link
        v-for="cat in categories"
        :key="cat.id"
        :to="`/products?categoryId=${cat.id}`"
        class="channel__pill"
      >
        <span class="channel__pill-icon">
          <component :is="catIcons[cat.id % catIcons.length]" />
        </span>
        <span class="channel__pill-name">{{ cat.name }}</span>
      </router-link>
    </div>

    <!-- 更多入口 -->
    <router-link to="/products" class="channel__more">
      全部分类 <el-icon><ArrowRight /></el-icon>
    </router-link>
  </div>
</nav>
```

**关键样式特征（对照 B 站）：**

| B 站特征 | B 站实现 | 电商适配 |
|----------|----------|----------|
| 频道链接卡片 | `border: 1px solid var(--line_light)` + `border-radius: 6px` | 同款 pill 样式 |
| hover 态 | 背景色 + 文字色变化 | `background: var(--bg3)` + `color: var(--brand-primary)` |
| 快速入口图标 | 圆形，40~46px，hover 变色 | 圆形图标容器，36px，hover 背景变品牌色浅底 |
| Grid 响应式 | `grid-template-columns: repeat(N, 1fr)` | 同策略，列数按视口递增 |
| 更多入口 | 右侧固定，文字 + 箭头 | 同款 |

**分类 pill 响应式 Grid 列数：**

| 视口宽度 | Grid 列数 | 说明 |
|----------|-----------|------|
| ≤768px | `repeat(3, 1fr)` | 平板竖屏 |
| 769~1024px | `repeat(5, 1fr)` | 小屏笔记本 |
| 1025~1440px | `repeat(7, 1fr)` | 标准桌面 |
| ≥1441px | `repeat(9, 1fr)` | 宽屏 |

#### 3.1.3 布局容器宽度

| 现状 | 计划 |
|------|------|
| `max-width: 1200px` | `max-width: 1280px`（对齐主流电商宽度） |

### 3.2 home/index.vue — 首页 Hero 区域重构

#### 结构变更

**现状：**
```
┌─── 240px 分类侧边栏 ───┬─── 轮播 Banner (400px) ───┐
```

**计划：**
```
┌─── 全宽轮播 Banner (360px, 16:6 比例) ───────────────┐
┌─── 分类卡片网格区（新增楼层） ─────────────────────────┐
┌─── 信任特性条 ───────────────────────────────────────┐
┌─── 热门商品 / 新品推荐（保持） ────────────────────────┐
```

#### 3.2.1 移除分类侧边栏

- 删除 `.hero__categories` 整块 HTML + 样式
- 分类数据获取逻辑上移到 `DefaultLayout.vue`（分类导航栏使用）
- `catIcons` 数组（`[Goods, ShoppingBag, Star, Present]`）需同步从 `home/index.vue` 迁移到 `DefaultLayout.vue`

#### 3.2.2 Banner 区调整

| 变更点 | 现状 | 计划 |
|--------|------|------|
| 高度 | 400px 固定 | 360px 固定（或 `max-height: 400px; aspect-ratio: 16/6`） |
| 宽度 | 与侧边栏分栏 | 全宽，border-radius: 12px |
| 文字区 | padding: 0 64px | padding: 0 80px（因全宽需更多留白） |
| 装饰图 | 右侧 SVG 180px | 右侧 SVG 200px（因全宽可放大） |
| 圆角 | 12px | 保持 12px |

#### 3.2.3 新增分类卡片楼层（`.category-floor`）

在 Banner 之后紧接分类卡片楼层，作为分类导航的"加强展示区"（信任特性条移至分类卡片之后）：

```
┌─── 分类卡片楼层 ──────────────────────────────────────┐
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │  🏷️ icon │ │  🏷️ icon │ │  🏷️ icon │ │  🏷️ icon │  │
│  │  分类名   │ │  分类名   │ │  分类名   │ │  分类名   │  │
│  │  N件商品  │ │  N件商品  │ │  N件商品  │ │  N件商品  │  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘  │
│  ...更多卡片（Grid 4→6→8 列响应式）...                  │
└──────────────────────────────────────────────────────┘
```

**分类卡片样式（参考 B 站视频卡 + 频道 pill 混合）：**
- 白色背景，`border-radius: 10px`，`box-shadow: var(--shadow-sm)`
- 居中布局，图标在上（48px）、名称居中（16px 加粗）、商品数在下（12px 灰色）
- hover：`transform: translateY(-4px)` + `box-shadow: var(--shadow-lg)`
- 过渡：`var(--transition-normal)`

> **实施前确认**：分类卡片中显示"N件商品"需确认 `getCategories()` 返回的 `Category` 类型是否包含 `productCount` 字段。若没有，需后端新增该字段或前端改用独立统计接口。若短期内无法获取，可用固定文案（如"去看看"）替代数字展示。

#### 3.2.4 信任特性条调整

- 从 4 列 Grid 保持不变
- 图标色统一为 `var(--brand-primary)`
- 圆角从 10px → 8px，与 pill 风格统一

| 变更点 | 现状 | 计划 |
|--------|------|------|

### 3.4 响应式断点策略（参考 B 站 5 级缩减为 4 级）

B 站 5 级断点针对的是千万级 UV 的视频平台，电商平台采用精简约 4 级：

| 断点 | 定位 | 调整内容 |
|------|------|----------|
| ≤768px | 移动端/小平板 | 分类导航折叠为横向滚动；Header 导航链接隐藏；Banner 装饰图隐藏；商品 Grid 2 列；分类卡片 Grid 3 列 |
| 769~1024px | 标准平板/小笔记本 | 分类导航 Grid 5 列；Header 搜索框缩小；商品 Grid 3 列；分类卡片 Grid 4 列 |
| ≥1025px | 标准桌面 | 完整双行 Header；分类导航 Grid 7 列；商品 Grid 4 列；分类卡片 Grid 6 列 |
| ≥1441px | 宽屏 | 分类导航 Grid 9 列；内容 max-width: 1280px 居中 |

> B 站的核心响应式思路：**不隐藏内容，而是调整列数、字号、间距来填入更多内容**。本方案同样贯彻这一原则。

> **移动端 Header 高度提醒**：双行 Header 在 ≤768px 合计约 108px（64+44），占小屏可视区域 15%+。移动端可将分类栏高度压缩为 36px、减小 pill padding 和字号，或改为横向滚动单行（可左右滑动），避免过度挤占内容空间。
