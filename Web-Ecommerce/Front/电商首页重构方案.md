### 1.2 分类体系（核心思想：一级/二级联动）

淘宝分类采用 **Hover 触发的二级面板** 模式：

```
左侧一级分类栏（常驻显示）          Hover时弹出的二级面板
┌──────────────────┐         ┌─────────────────────────────┐
│ 图标  618现货抢先购  │ ─────→ │  二级分类标题                 │
│ 图标  近期热卖      │        │  618现货抢先购  →           │
│ 图标  热门推荐      │        │  ┌───────────────────────┐ │
│ 图标  性价之选      │        │  │ 大额券  官方立减8.5折起  │ │
│ 图标  好评推荐      │        │  │ 抢补贴  企业采购叠券     │ │
│ 图标  居家幸福感    │        │  │ ...                   │ │
│ 图标  宝妈必备      │        │  └───────────────────────┘ │
│ ...              │        │                             │
└──────────────────┘        │  二级分类标题                 │
                             │  近期热卖  →               │
                             │  ┌───────────────────────┐ │
                             │  │ 邀请好友 100%得红包     │ │
                             │  │ OpenClaw 小龙虾        │ │
                             │  │ ...                   │ │
                             │  └───────────────────────┘ │
                             └─────────────────────────────┘
```

**关键设计要点：**

| 层级 | 展示位置 | 交互方式 | 内容 |
|------|---------|---------|------|
| 一级分类 | 左侧竖列（常驻） | Hover / Click | 图标 + 分类名 + 右侧箭头 |
| 二级分类 | 右侧弹出面板（792px宽） | Hover 一级时显示 | 二级标题组 + 三级关键词链接 |
| 三级内容 | 二级面板内的标签链接 | Click 跳转 | 具体搜索/筛选关键词 |

**分类栏行为：**
- 页面初始状态：分类栏展开（全部一级分类可见）
- 向下滚动后：分类栏收起（`collapsed`），仅显示一个小标签
- 鼠标移入：展开完整分类面板

### 1.3 轮播图（Central Carousel）

使用 **Slick Carousel** 实现：
- **5 张轮播图**，尺寸 561×400
- 圆形背景图片 + 文字叠加层
- 导航方式：左右箭头 + 底部圆点指示器
- 自动轮播 + 手动拖拽
- 每张 slide 含三层文字：`title-top` / `title-middle` / `subtitle`

轮播内容结构：
```
┌──────────────────────┐
│  [banner-icon 小标]   │
│                      │
│  标题（顶部小字）       │
│  标题（中间大字）       │
│  副标题（底部描述）     │
│                      │
│       背景图片         │
└──────────────────────┘
```

### 1.4 右侧卡片列（Right Cards）

- 4 张竖排排列的静态推广卡片
- 每张 512×176，背景图填充
- 间距 16px（通过 `margin-top` 实现）
- 纯展示 + 点击跳转，无轮播

## 二、当前首页问题诊断

| 问题 | 说明 |
|------|------|
| 分类区扁平 | 仅做 6 列 grid 卡片平铺，没有利用 `parentId`/`children` 的层级关系 |
| 轮播独占全宽 | 轮播图 1280px 全宽，没有与分类形成联动布局，空间利用低效 |
| 缺少右侧卡片 | 右侧推广位完全缺失，失去了同时展示多营销入口的能力 |
| 分类与轮播分离 | 分类在轮播下方独立成块，与淘宝"分类旁即轮播"的信息架构不同 |

### 3.2 分类侧边栏设计

#### 数据结构转换

当前 `Category` 接口：
```ts
interface Category {
  id: number
  name: string
  parentId: number    // 0 = 一级分类
  sortOrder: number
  children?: Category[]
  productCount?: number  // 现有代码用到
}
```

**重构逻辑：**
- 请求 `getCategories()` 后，按 `parentId === 0` 筛出一级分类
- 每个一级分类的 `children` 即为二级分类
- 构建两级结构用于侧边栏展示

#### 视觉设计

```
┌─────────────────────┐
│  全部商品分类         │  ← 标题栏（橙色/品牌色背景）
├─────────────────────┤
│  👗  女装 / 男装     │  ← 一级分类行（hover 高亮）
│  📱  数码家电        │     左侧图标 + 名称 + 右侧箭头
│  🍜  食品生鲜        │
│  🏠  居家生活        │
│  💄  美妆护肤        │
│  👟  运动户外        │
│  📚  图书文娱        │
│  ...               │
└─────────────────────┘
```

#### 交互方案（两种可选）

**方案 A：Hover 弹出二级面板（推荐，仿淘宝）**
- 鼠标悬停一级分类 → 右侧浮出二级面板（绝对定位）
- 面板内按二级分类分组，每组含标题 + 子链接
- 鼠标移出 → 面板消失
- 优点：信息密度高，视觉冲击力强
- 缺点：移动端不适配

**方案 B：Click 展开手风琴**
- 点击一级分类 → 下方展开二级分类子项
- 再次点击 → 收起
- 优点：移动端友好，实现简单
- 缺点：信息密度低

**建议：** 桌面端用方案 A（Hover 弹出），移动端降级为方案 B（手风琴）或直接跳转分类页

### 3.3 轮播图改造

将现有全宽轮播改为三列布局中的中央列：

**改动点：**
- 去掉 `hero__slide-art` SVG 装饰（或缩小到角落）
- 轮播高度从 360px 提升到 400px（与右侧卡片列对齐）
- 轮播宽度由父容器自动决定（flex: 1）
- 保留渐变色背景 + 文字 + CTA 按钮的结构
- 保留 `arrow="always"` 和 `interval="5000"`

```html
<!-- 新轮播结构 -->
<div class="hero-center">
  <el-carousel height="400px" :interval="5000" arrow="always">
    <el-carousel-item v-for="(b, i) in banners" :key="i">
      <div class="carousel-slide" :style="{ background: b.bg }">
        <div class="carousel-slide__text">
          <span class="carousel-slide__tag">{{ b.tag }}</span>
          <h2>{{ b.title }}</h2>
          <p>{{ b.subtitle }}</p>
          <el-button type="primary" round>立即选购</el-button>
        </div>
      </div>
    </el-carousel-item>
  </el-carousel>
</div>
```

### 3.4 右侧推广卡片

4 张竖排推广卡片，作为静态入口：

```html
<div class="hero-right">
  <div
    v-for="(card, i) in rightCards"
    :key="i"
    class="promo-card"
    :style="{ background: card.bg }"
    @click="$router.push(card.link)"
  >
    <span class="promo-card__title">{{ card.title }}</span>
    <span class="promo-card__desc">{{ card.desc }}</span>
  </div>
</div>
```

默认数据（可后续对接后端）：


### 3.5 响应式适配

| 断点 | 布局策略 |
|------|---------|
| ≥1280px | 三列完整显示：分类 200px + 轮播 flex(1) + 右侧 200px |
| 1024–1279px | 分类收缩为图标模式（~50px），轮播 + 右侧保持 |
| 768–1023px | 隐藏右侧卡片列，分类折叠为汉堡菜单入口，轮播全宽 |
| <768px | 分类入口移入顶部导航，轮播全宽，高度 200px |

### 3.6 不做什么

- 不改动现有信任特性栏、热门商品、新品推荐、促销横幅等楼层
- 不创建新的 API 接口（利用现有 `getCategories()` 和 `children` 字段）
- 不改变现有 ProductCard 组件
- 不改变路由和 Pinia store 结构
