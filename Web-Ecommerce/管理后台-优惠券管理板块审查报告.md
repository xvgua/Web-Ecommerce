## 四、后端 API 设计

### 4.1 管理员优惠券接口

**基路径：** `/api/admin/coupons`

| 方法 | 路径 | 说明 | 请求体/参数 |
|------|------|------|------------|
| GET | `/api/admin/coupons` | 分页列表 | `?page=&pageSize=&keyword=&type=&status=` |

### 4.3 DTO：CouponForm

```java
// dto/CouponForm.java
public class CouponForm {
    @NotBlank(message = "券名称不能为空")
    private String name;

    @NotNull(message = "优惠类型不能为空")
    @Min(1) @Max(3)
    private Integer type;           // 1=满减 2=折扣 3=免邮

    @NotNull(message = "优惠值不能为空")
    private BigDecimal discount;    // 满减=金额, 折扣=折扣率(0~1)

    private BigDecimal minAmount;   // 使用门槛，默认0

    @NotNull(message = "发行总量不能为空")
    @Min(1)
    private Integer totalQty;

    @NotNull(message = "开始时间不能为空")
    private LocalDateTime startTime;

    @NotNull(message = "结束时间不能为空")
    private LocalDateTime endTime;

    private LocalDateTime grabStartTime;  // 抢购开始（大额券）
    private LocalDateTime grabEndTime;    // 抢购结束（大额券）

    private Integer scopeType;      // 1=通用 2=分类 3=商品

    private Integer isLarge;        // 0=小额 1=大额

}
```

### 关键实现逻辑

#### adminCreate()
- 根据 type 校验 discount 值的合理性（满减>0，折扣在0~1）
- isLarge=1 时校验 grabStartTime/grabEndTime 不为空且合理
- scopeType≠1 时校验 scopeIds 不为空
- totalQty 初始化为 remainQty
- 插入 coupon 记录

#### adminUpdate()
- 仅允许编辑尚未被领取的券（检查 user_coupon 表中是否有记录）
- 如果已有用户领取，仅允许修改有效期和状态，不允许修改优惠金额/类型
- 已领取的券编辑时，增加 totalQty 必须 ≥ 已领取数量

#### adminDelete()
- 仅允许删除未被领取的券
- 已领取的券不允许删除（改为停用）

## 九、小结

管理后台目前完全没有优惠券管理功能。需要新增的内容核心为：

1. **`views/coupon/index.vue`** — 遵循现有列表页模式（搜索+表格+分页），增加券类型标签、库存进度条、适用范围的差异化展示
2. **`views/coupon/form.vue`** — 遵循现有表单页模式（el-card+el-form），增加类型切换、抢购设置、适用范围选择、券卡片实时预览
3. **后端 `AdminCouponController`** — 完整的优惠券 CRUD（含上下架），按管理员鉴权

表单页的"券卡片实时预览"是区别于其他管理页面的特色功能，直接参考 `领券中心.html` 中 `cpItemWrapper` 的视觉设计，让管理员在创建优惠券时就能看到用户端的效果。
