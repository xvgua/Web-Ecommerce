# 商品规格功能 — 天猫对照审查报告

## 一、天猫参考页特征

**参考页面**：信越7921导热硅脂 — tmall.com 商品详情页

**SKU 选择区的结构**：

```
┌─ 商品规格 ──────────────────────────────────────────────────┐
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │   [缩略图]    │  │   [缩略图]    │  │   [缩略图]    │      │
│  │ 7868：1克    │  │ 7868：2克    │  │ 7868：3克    │      │
│  │ +顺丰包邮    │  │ +拆机清灰    │  │ +拆机清灰    │ ...  │
│  │ +送涂抹工具   │  │ 九件套       │  │ 九件套       │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │   [缩略图]    │  │   [缩略图]    │  │   [缩略图]    │      │
│  │ 7921：1克    │  │ 7921：2克    │  │ 7921：3克    │ ...  │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**天猫的核心特征**：

| 特征 | 说明 |
|------|------|
| 统一分组标签 | 一个「商品规格」标签覆盖所有 SKU，不按 specName 拆分子分组 |
| 图片卡片布局 | 每个 SKU 是一张小卡片：缩略图在上 + 描述文字在下 |
| 完整描述文字 | 规格文字是完整的营销描述（`7921：2克+顺丰包邮+拆机清灰九件套`），不是简单 KV |
| 视觉选中态 | 2px 蓝色边框 + 浅蓝背景，视觉冲击力强 |
| 缺货禁用态 | 库存为 0 的 SKU 呈现灰色蒙层，不可点击 |
| 网格排列 | 每行多个 SKU（类似商品列表），非横向平铺标签 |

## 二、当前实现与天猫差距

| 维度 | 天猫 | 当前实现 | 差距 |
|------|------|----------|------|
| SKU 展示形式 | 图片卡片（缩略图 + 多行描述） | 纯文字小标签 `<span class="spec-tag">` | **大** |
| SKU 文字内容 | 完整规格描述（型号：克数+附加信息） | `specName:specValue`（如 `颜色:深空灰`） | **大** |
| SKU 图片 | 每个 SKU 有独立缩略图 | 无此字段 | **大** |
| 规格分组标签 | 统一「商品规格」标签 | 无分组标题 | 中 |
| 选中态样式 | 蓝色 2px 边框 + 背景色 + 加粗 | 边框变色 + 浅背景，对比度偏弱 | 中 |
| 缺货禁用态 | 灰色蒙层 + `data-disabled="true"` | 未处理 `stock === 0` | 中 |
| 管理端输入 | — | 规格名 + 规格值 拆分输入 | 中（与天猫 SKU 描述模式不匹配） |

## 三、需要调整的部分

### 3.1 数据库 — product_sku 表增加 image 字段

**当前 Schema**：

```sql
CREATE TABLE `product_sku` (
  id          BIGINT AUTO_INCREMENT PRIMARY KEY,
  product_id  BIGINT         NOT NULL,
  spec_name   VARCHAR(50)    NOT NULL,
  spec_value  VARCHAR(50)    NOT NULL,
  price       DECIMAL(10,2)  NOT NULL,
  stock       INT            DEFAULT 0
);
```

**需调整为**：

```sql
ALTER TABLE `product_sku` ADD COLUMN image VARCHAR(255) DEFAULT NULL COMMENT '规格缩略图';
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `image` | `VARCHAR(255)` | 否 | SKU 缩略图 URL，无图时留空（降级为纯文字标签） |

### 3.3 用户端 — 商品详情页 SKU 展示重构

**涉及文件**：`client/src/views/product/detail.vue`

#### 3.3.1 布局：文字标签 → 图片卡片网格

**当前**（纯文字标签，横排排列）：

```html
<div class="spec-options">
  <span v-for="sku in product.skus" :class="['spec-tag', { 'spec-tag--active': ... }]">
    {{ sku.specName }}:{{ sku.specValue }}
  </span>
</div>
```

**需调整为**（图片卡片，多列网格）：

```html
<div class="spec-options">
  <div v-for="sku in product.skus"
       :class="['sku-card', {
         'sku-card--active': selectedSkuId === sku.id,
         'sku-card--disabled': sku.stock === 0
       }]"
       @click="sku.stock > 0 && (selectedSkuId = sku.id)"
  >
    <div class="sku-card__img" v-if="sku.image">
      <img :src="sku.image" :alt="sku.specValue" />
    </div>
    <div class="sku-card__text">{{ sku.specName }}:{{ sku.specValue }}</div>
    <div class="sku-card__price" v-if="sku.price !== product.price">
      {{ formatPrice(sku.price) }}
    </div>
  </div>
</div>
```

**技术规约**：

| 约束 | 说明 |
|------|------|
| 网格列数 | 桌面端 4 列，平板 3 列，移动端 2 列（`grid-template-columns: repeat(4, 1fr)` + media query） |
| 选中态 | `2px solid #409eff` 边框 + `rgba(64,158,255,.08)` 背景 + `font-weight: 600` |
| 缺货态 | `opacity: 0.45` + `cursor: not-allowed` + 灰色 overlay 文字「已售罄」 |
| 缩略图 | `width: 100%; aspect-ratio: 1; object-fit: cover; border-radius: 6px` |
| hover | 非禁用状态 hover 时边框变蓝（`border-color: #409eff`） |

#### 3.3.2 缺货 SKU 禁用逻辑

当前所有 SKU 均可点击选中，未判断 `stock === 0`。

**需调整**：

```ts
// detail.vue — handleAddToCart 中增加缺货校验
const selectedSku = computed(() =>
  product.value?.skus?.find(s => s.id === selectedSkuId.value)
)

async function handleAddToCart() {
  if (product.value?.skus?.length && !selectedSkuId.value) {
    ElMessage.warning('请选择商品规格')
    return
  }
  if (selectedSku.value && selectedSku.value.stock === 0) {
    ElMessage.warning('该规格已售罄')
    return
  }
  // ... existing logic
}
```

**技术规约**：

| 约束 | 说明 |
|------|------|
| 点击拦截 | `@click` 中增加 `sku.stock > 0` 前置条件 |
| 按钮状态 | 选中缺货 SKU 时「加入购物车」按钮 disabled |
| 后端防护 | 保持现有库存乐观锁（已实现），前端仅做 UX 优化 |

#### 3.3.3 分组标签优化

**当前**：无分组标题。

**需调整**：规格区域加统一「商品规格」标题（已存在 `<h4>规格</h4>`，调整为 `<h4>商品规格</h4>`）。
