## 二、当前实现 vs 需求对比

### 2.1 数据库字段对照

| 需求 | 当前字段 | 状态 | 缺口 |
|------|---------|------|------|
| 优惠券有效期 | `start_time` / `end_time` | ✅ 已有 | — |
| 数量限制 | `total_qty` / `remain_qty` | ✅ 已有 | — |
| 优惠券类型 | `type` (1/2/3) | ✅ 已有 | 仅区分满减/折扣/免邮 |
| 抢购时间窗口 | — | ❌ 缺失 | 大额券需要独立抢购时间段 |
| 适用分类范围 | — | ❌ 缺失 | 无法限制券的适用范围 |
| 是否大额标记 | — | ❌ 缺失 | 无法区分大额/小额券 |

### 2.2 业务逻辑对照

| 场景 | 当前行为 | 期望行为 |
|------|---------|---------|
| 大额券还未到抢购时间 | 只要在 `start_time`~`end_time` 内即可领 | 需等待抢购开始时刻才能领 |
| 优惠券适用商品范围 | 无限制，所有商品可用 | 按分类/指定商品限制使用 |
| 抢购倒计时展示 | 无 | 大额券显示倒计时，小额券直接领 |
| 按分类筛选优惠券 | 无 | 可按商品分类筛选可用券 |

## 三、增强方案

### 3.1 数据库改动

在 `coupon` 表新增 3 个字段：

```sql
ALTER TABLE `coupon`
  ADD COLUMN `grab_start_time` DATETIME DEFAULT NULL COMMENT '抢购开始时间（NULL=无抢购限制，即小额券）',
  ADD COLUMN `grab_end_time`   DATETIME DEFAULT NULL COMMENT '抢购结束时间',
  ADD COLUMN `scope_type`      TINYINT  DEFAULT 1 COMMENT '适用范围: 1=通用 2=指定分类 3=指定商品',
  ADD COLUMN `scope_ids`       VARCHAR(500) DEFAULT '' COMMENT '适用范围ID列表(JSON数组)，scope_type=2时存categoryId，=3时存productId',
  ADD COLUMN `is_large`        TINYINT  DEFAULT 0 COMMENT '是否大额券: 0=小额 1=大额（有抢购时间）';
```

**字段说明：**

| 字段 | 作用 | 示例 |
|------|------|------|
| `grab_start_time` | 抢购开始时刻，NULL 表示无抢购限制 | `2026-06-01 10:00:00` |
| `grab_end_time` | 抢购结束时刻 | `2026-06-01 12:00:00` |
| `scope_type` | 1=通用券，2=分类券，3=单品券 | `2` |
| `scope_ids` | 当 scope_type≠1 时，存储限制的分类ID或商品ID | `[1,6,7]`（手机数码分类） |
| `is_large` | 是否大额券，决定是否显示倒计时 | `1` |

> **小额券 vs 大额券判断逻辑**：`is_large=1` 且 `grab_start_time` 不为 NULL → 大额券，显示抢购倒计时；其余 → 小额券，直接可领。

### 3.2 优惠券完整生命周期

```
                    抢购窗口                  使用有效期
              |──────────────────|  |──────────────────────────────|
    创建 ──→ grab_start_time  grab_end_time  start_time ──→ end_time ──→ 过期
              |                 |             |
              未开始(倒计时)    可抢购         已领完/已领取
              (按钮不可点)     (按钮可点)     (按钮灰)
```

- **未开始**：`now < grab_start_time` → 显示倒计时
- **可抢购**：`grab_start_time ≤ now ≤ grab_end_time` → 可领取
- **已结束抢购**：`now > grab_end_time` → 不可再领
- **小额券**：`grab_start_time IS NULL` → 不展示倒计时，`start_time ≤ now ≤ end_time` 期间随时可领

### 3.3 Java 实体改动

// Coupon.java 新增字段
private LocalDateTime grabStartTime;   // 抢购开始时间
private LocalDateTime grabEndTime;     // 抢购结束时间

private String scopeIds;               // 适用范围ID列表(JSON)

### 3.4 后端逻辑改动

#### CouponServiceImpl.receiveCoupon()

```java
// 新增抢购时间校验（仅大额券）
if (coupon.getIsLarge() == 1 && coupon.getGrabStartTime() != null) {
    LocalDateTime now = LocalDateTime.now();
    if (now.isBefore(coupon.getGrabStartTime())) {
        throw new BusinessException("抢购尚未开始");
    }
    if (coupon.getGrabEndTime() != null && now.isAfter(coupon.getGrabEndTime())) {
        throw new BusinessException("抢购已结束");
    }
}
```

#### CouponServiceImpl.getAvailableCoupons()

```java
// 新增分类筛选参数
public PageResult<Coupon> getAvailableCoupons(Long userId, Integer categoryId, int page, int pageSize) {
    // ...
    if (categoryId != null) {
        wrapper.and(w -> w.eq(Coupon::getScopeType, 1)  // 通用券
                .or().like(Coupon::getScopeIds, String.valueOf(categoryId)));  // 该分类可用
    }
    // 按 is_large 排序，大额券靠前
    wrapper.orderByDesc(Coupon::getIsLarge);
}
```
