**文件:** `Back/.../mapper/ReviewMapper.java`

现有 `selectByProductId` 只查 review 表字段。需要新增方法：

```java
// 查询用户本人的评价列表（JOIN product 表获取商品信息）
@Select("<script>SELECT r.*, p.name AS product_name, p.main_image AS product_image, p.price " +
        "FROM review r LEFT JOIN product p ON r.product_id = p.id " +
        "WHERE r.user_id = #{userId} AND r.is_followup = 0 " +
        "ORDER BY r.create_time DESC LIMIT #{offset}, #{pageSize}</script>")
List<Review> selectByUserId(@Param("userId") Long userId, int offset, int pageSize);

@Select("SELECT COUNT(*) FROM review WHERE user_id = #{userId} AND is_followup = 0")
long countByUserId(@Param("userId") Long userId);
```

## 三、需新增项（完全缺失的功能）

### 3.1 点赞功能（全套新增）

#### 3.1.1 数据库 — 新增点赞表

```sql
CREATE TABLE IF NOT EXISTS `review_like` (
  id          BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id     BIGINT   NOT NULL,
  review_id   BIGINT   NOT NULL,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_review (user_id, review_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.2 数据库 — review 表加 `like_count`

```sql
ALTER TABLE `review` ADD COLUMN `like_count` INT DEFAULT 0 COMMENT '点赞数';
```

#### 3.1.3 后端 — 新增实体、Mapper、Service、Controller

| 层                             | 说明                                                             |
| ------------------------------ | ---------------------------------------------------------------- |
| `entity/ReviewLike.java`       | id, userId, reviewId, createTime                                 |
| `mapper/ReviewLikeMapper.java` | insert / delete / count / exists                                 |
| `service/ReviewService`        | `likeReview(userId, reviewId)`、`unlikeReview(userId, reviewId)` |
| `controller/ReviewController`  | `POST /api/reviews/:id/like`、`DELETE /api/reviews/:id/like`     |

点赞逻辑：

- 一个用户对同一条评价只能点赞一次（`UNIQUE KEY` 保证）
- 点赞时 `UPDATE review SET like_count = like_count + 1`
- 取消点赞时 `UPDATE review SET like_count = like_count - 1`
- 查询评价时返回 `like_count` 以及 `isLiked`（当前用户是否已点赞）

#### 3.1.4 前端 — UI

- 评价列表每项底部加"点赞"按钮（图标 + 数字）
- 已点赞显示实心红色，未点赞显示空心
- 点击切换点赞/取消，使用乐观更新

### 3.2 评论功能（全套新增）

> **注意区分概念**：此处的"评论"是指用户对**评价**的回复/讨论（类似淘宝的"评价下的留言"），而非商品评价本身。
> 如果需求中的"评论数"指的是该评价被回复的次数，则按此方案；如果指的是"评价总数"，则 product 表的 `review_count` 已有。

#### 3.2.1 数据库 — 新增评论表

```sql
CREATE TABLE IF NOT EXISTS `review_comment` (
  id          BIGINT AUTO_INCREMENT PRIMARY KEY,
  review_id   BIGINT       NOT NULL,
  user_id     BIGINT       NOT NULL,
  username    VARCHAR(50)  NOT NULL,
  avatar      VARCHAR(500) DEFAULT '',
  content     TEXT         NOT NULL,
  create_time DATETIME     DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_review_id (review_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.2.2 数据库 — review 表加 `comment_count`

```sql
ALTER TABLE `review` ADD COLUMN `comment_count` INT DEFAULT 0 COMMENT '评论数';
```

#### 3.2.3 后端 — 新增实体、Mapper、Service、Controller

| 层                                | 说明                                                              |
| --------------------------------- | ----------------------------------------------------------------- |
| `entity/ReviewComment.java`       | id, reviewId, userId, username, avatar, content, createTime       |
| `mapper/ReviewCommentMapper.java` | insert / selectByReviewId / count                                 |
| `service/ReviewService`           | `addComment(userId, reviewId, content)`                           |
| `controller/ReviewController`     | `POST /api/reviews/:id/comments`、`GET /api/reviews/:id/comments` |

#### 3.2.4 前端 — UI

- 评价列表每项底部加"评论"入口（图标 + 数量）
- 点击展开评论列表（或弹窗），显示已有评论
- 提供评论输入框，支持提交

**路由:** `/user/reviews`（需登录）

**页面结构:**

**页面职责:**

- 导航栏用户下拉菜单增加"我的评价" → `/user/reviews`

- 点击"追评"按钮 → 跳转 `/orders/:orderId/review/:productId?followUp=1`

## 六、实施建议

1. **优先级 1**（核心需求）：后端 `GET /api/reviews/mine` + 前端"我的评价"页面（含评价日期 + 商品简细）

3. **优先级 3**（讨论功能）：评论表 + 评论 API + 前端评论 UI
4. **优先级 4**（辅助）：ReviewMapper SQL 补全、评价删除、管理端评价管理
