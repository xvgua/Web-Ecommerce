# 需求澄清文档 — 后台商品评价管理

> **版本**: v2.0（已确认）  
> **日期**: 2026-06-05  
> **状态**: 已确认，进入开发  

---

## 一、需求概述

为后台管理系统新增**商品评价管理**模块，管理员可以查看所有用户评价，并对违规评价进行删除处理。

---

## 二、确认结论汇总

| 编号 | 问题 | 结论 |
|------|------|------|
| Q1 | 评价详情弹窗 | **需要**，列表展示缩略图，点击弹窗查看大图+完整内容+评论 |
| Q2 | 单独删除追评 | **不需要**，删除整条评价时一并删除追评 |
| Q3 | 批量删除 | **需要**，勾选多条后一键删除 |
| Q4 | 删除原因记录 | **不需要** |
| Q5 | 评价统计面板 | **不需要（暂）** |
| Q6 | 订单编号列 | **需要**，列表显示 `orderId` |
| Q7 | 评价类型列 | **不需要**，用标签标记有追评的首评即可 |
| Q8 | 举报次数字段 | **不需要** |
| Q9 | 用户名称搜索 | **需要** |
| Q10 | 有图/无图筛选 | **需要** |
| Q11 | 按点赞数排序 | **需要** |
| Q12 | 软删除 vs 硬删除 | **硬删除**，直接物理删除 |
| Q13 | 恢复功能 | **不需要** |
| Q14 | 删除确认展示摘要 | **需要**，弹窗展示"确定删除用户【xxx】对【商品名】的评价吗？" |
| Q15 | 接口设计 | **OK**，按草案执行 |
| Q16 | 商品名称/图片 | **后端 JOIN 返回** |
| Q17 | 菜单位置 | **商品管理**子菜单下 |

---

## 三、功能范围（定稿）

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 评价列表 | 分页展示所有首评，含商品图片/名称、用户头像/用户名、评分、内容截断、图片缩略图、订单号、追评标签、点赞/评论数、时间 |
| F2 | 搜索筛选 | 商品名称模糊搜索、用户名称模糊搜索、评分筛选、时间范围筛选、有图/无图筛选、有追评/无追评筛选、按点赞数排序 |
| F3 | 删除评价 | 单条硬删除（二次确认弹窗展示评价摘要），级联删除追评+评论+点赞，重算商品评分 |
| F4 | 批量删除 | 勾选多条后一键批量删除，同样级联+重算 |
| F5 | 评价详情弹窗 | 大图预览、完整评价内容、追评内容、全部评论列表 |

---

## 四、后端接口（定稿）

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/admin/reviews` | 分页查询（支持搜索/筛选/排序） |
| `GET` | `/api/admin/reviews/{id}` | 评价详情（含追评+评论列表） |
| `DELETE` | `/api/admin/reviews/{id}` | 删除单条（级联+重算评分） |
| `DELETE` | `/api/admin/reviews/batch` | 批量删除（请求体 `{ ids: [...] }`） |

列表接口参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `page` | int | 页码，默认 1 |
| `pageSize` | int | 每页条数，默认 10 |
| `keyword` | String | 商品名称模糊搜索 |
| `username` | String | 用户名称模糊搜索 |
| `rating` | Integer | 评分筛选，1-5 |
| `startDate` | String | 开始日期，格式 yyyy-MM-dd |
| `endDate` | String | 结束日期，格式 yyyy-MM-dd |
| `hasImage` | Boolean | true=有图，false=无图 |
| `hasFollowUp` | Boolean | true=有追评，false=无追评 |
| `sort` | String | `newest`（默认）/`most_liked`（按点赞数降序） |

## 五、技术实现方案

### 5.1 后端
- `ReviewMapper` 新增 `selectAdminList` / `countAdminList`（LEFT JOIN product，动态 SQL 筛选）
- `ReviewService` / `ReviewServiceImpl` 新增管理端方法
- 新建 `AdminReviewController`，路径 `/api/admin/reviews`
- 删除使用 `@Transactional`，先删关联数据（追评→评论→点赞），再删首评，最后重算商品评分

### 5.2 前端
- `admin.ts` 新增 4 个 API 函数
- 新建 `views/review/index.vue`
- 路由 `/reviews`，meta title "评价管理"
- 侧边栏"商品管理"子菜单新增"评价管理"
- 参照 `refund/index.vue` 的页面模式
