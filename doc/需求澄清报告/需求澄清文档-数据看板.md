## 一、需求概述

升级管理后台数据看板，在现有核心数据统计基础上，新增**销量趋势图**、**热销商品排行**和**订单状态统计图**三块数据可视化模块。

## 二、现状分析

### 2.1 已具备

| ------------ | ------------------------------------------------------------------------ |
| 5 张统计卡片 | 总用户数、总订单数、总销售额、今日订单、今日销售额 — 后端 API 已就绪     |

### Q1 — 图表库选型

当前前端无图表依赖，需要引入图表库。

| 选项                  | 包名                       | 包大小      | Vue 3 支持 | 说明                                    |
| --------------------- | -------------------------- | ----------- | ---------- | --------------------------------------- |
| **A. ECharts** (推荐) | `echarts` + `vue-echarts`  | ~1MB gzip   | 官方支持   | 功能最全，中文文档好，Element Plus 生态 |
| B. Chart.js           | `chart.js` + `vue-chartjs` | ~200KB gzip | 社区适配   | 轻量，功能较少                          |

## 五、技术方案

### 5.1 后端新增

#### 5.1.1 销量趋势 API

```
GET /api/admin/dashboard/sales-trend?range=7d|30d|month

请求参数:
  range: String (默认 "7d")

响应:
{
  code: 200,
  data: [
    { date: "2026-05-30", orderCount: 12, salesAmount: 34560.00 },
    { date: "2026-05-31", orderCount: 8,  salesAmount: 18900.00 },
    ...
  ]
}

实现要点:
  - SQL 聚合 order 表（status NOT IN (4,5) 已取消/退款中）
  - GROUP BY DATE(create_time)，按天聚合
  - 7d → 最近 7 天；30d → 最近 30 天；month → 当月 1 日至今
  - 无订单的日期补 0
```

#### 5.1.2 热销商品排行 API

```
GET /api/admin/dashboard/hot-products?range=all|week|month&top=10

请求参数:
  range: String (默认 "all")
  top:   int    (默认 10)

响应:
{
  code: 200,
  data: [
    { id: 11, name: "Kingston DDR5 32GB", mainImage: "...", sales: 678, salesAmount: 541722.00 },
    ...
  ]
}

实现要点:
  - range=all:    直接用 product.sales 降序取 top
  - range=week:   order_item JOIN `order` 聚合本周内销量，GROUP BY product_id
  - range=month:  同上，本月范围
  - salesAmount = SUM(order_item.price * order_item.quantity)
```

#### 5.1.3 订单状态分布 API

> 复用现有 `GET /admin/dashboard/stats` 中的 pendingOrders/shippingOrders/completedOrders/cancelledOrders，前端自行计算百分比。不新增独立接口。
