# 微服务架构拆分 — 对比报告

> 对比基准：拆分前单体架构 (Back/) vs 拆分后微服务架构  
> 生成日期：2026-06-05

---

## 一、架构对比

### 1.1 部署拓扑

| 维度 | 拆分前（单体） | 拆分后（微服务） |
|------|---------------|------------------|
| 服务数量 | 1 个 backend | 4 个（gateway + 3 services） |
| 数据库 | 1 个 MySQL `ecommerce` | 3 个 MySQL (`ecommerce_user/product/order`) |
| 容器数 | 5 个 | 8 个 |
| 端口 | 8080 (backend) | 8080 (gateway), 8082-8084 (services) |
| 服务通信 | 进程内方法调用 | HTTP (Feign) |
| 鉴权位置 | 各服务拦截器解析 JWT | Gateway 统一解析 JWT → 请求头 |

### 1.2 调用链路变化

```
拆分前:  Frontend → backend:8080 → 直接查 MySQL

拆分后:  Frontend → gateway:8080 → lb://user-service:8082
                                 → lb://product-service:8083
                                 → lb://order-service:8084
                                                     ├── Feign → product-service
                                                     └── Feign → user-service
```

## 五、数据库变化

| 变化项 | 说明 |
|--------|------|
| 数据库数量 | 1 → 3 (`ecommerce_user`, `ecommerce_product`, `ecommerce_order`) |
| 主键策略 | `AUTO_INCREMENT` → MyBatis-Plus `assign_id`（雪花算法） |
| 跨库 JOIN | 不再可能 — 改为 Feign 批量查询 + 内存组装 |
| 事务边界 | 单库 `@Transactional` → 仍需跨库事务（预留 Seata `@GlobalTransactional`） |
| `undo_log` 表 | 各库需单独创建（Seata AT 模式前置条件，暂未启用） |

### 表分配详情

| 数据库 | 表名 | 数量 |
|--------|------|------|
| `ecommerce_user` | user, admin, address, feedback, conversation, chat_message, quick_reply, announcement | 8 |
| `ecommerce_product` | product, product_sku, category, banner, favorite, seckill_activity, seckill_product, search_log, hot_keyword | 9 |
| `ecommerce_order` | cart, `order`, order_item, payment_session, review, review_comment, review_like, coupon, user_coupon | 9 |

## 七、鉴权方案变化

| 维度 | 拆分前 | 拆分后 |
|------|--------|--------|
| JWT 解析位置 | 各服务的 LoginInterceptor | Gateway AuthFilter（仅一次） |
| 用户信息传递 | ThreadLocal (JWT 解析) | HTTP 请求头 `X-User-Id` / `X-User-Role` |
| 管理员鉴权 | AdminInterceptor (解析 JWT + 角色) | Gateway AdminAuthFilter → `X-User-Role` 请求头 |
| Token 黑名单 | 各服务查 Redis | Gateway AuthFilter 查 ReactiveRedis |
| 下游拦截器 | LoginInterceptor + AdminInterceptor | UserContextInterceptor（仅读请求头） |
| JWT 工具 | Servlet JwtUtils (1 个) | 共用 JwtUtils (common 模块)；Gateway 通过 WebFlux 调用 |

## 八、已移除的功能（需后续补充）

| 功能 | 原因 | 影响 |
|------|------|------|
| 商品详情页评价加载 | product-service 不能调 order-service | 前端需改为直接调 `/api/reviews?productId={id}` |
| 秒杀订单创建 | product-service 不能调 order-service | 需在 order-service 中新增 `/api/orders/seckill` 端点 |
| 秒杀已购状态 | 同上 | 需通过 order-service 查询 |
| 秒杀订单超时释放 | product-service 无 order Mapper | 需在 order-service 中新增定时任务 |
| 用户总数统计（看板） | order-service 无 UserMapper | 通过 Feign `getAllUsers()` 获取（已实现） |
