# 订单导出（Excel）需求澄清

## 1. 导出范围

**Q1: 导出哪些订单？**

- A. 导出当前筛选条件下的全部订单（跟随搜索栏的订单号、用户ID、订单状态筛选） ✅
- B. 导出所有订单（忽略筛选条件）
- C. 支持勾选订单后批量导出选中项
- D. A + C 组合（默认导出筛选结果，也支持勾选导出）

**Q2: 导出数据量是否需要限制？**

- A. 不限制，导出全部匹配订单
- B. 设置上限（如最多导出 10000 条），超出时提示用户缩小筛选范围 ✅
- C. 支持分批次导出（每次最多 N 条，提供"导出全部/导出本页"两个按钮）

---

## 2. 导出字段

**Q3: 订单主表需要导出哪些字段？**

| 字段         | 说明              | 决定     |
| ------------ | ----------------- | -------- |
| 订单编号     | order_no          | 包含 ✅   |
| 用户ID       | user_id           | 包含 ✅   |
| 收货人       | address.name      | 包含 ✅   |
| 联系电话     | address.phone     | 包含 ✅   |
| 收货地址     | address 拼接      | 包含 ✅   |
| 商品原价合计 | total_amount      | 包含 ✅   |
| 优惠券抵扣   | coupon_discount   | 包含 ✅   |
| 商品折扣     | discount_amount   | 包含 ✅   |
| 实付金额     | pay_amount        | 包含 ✅   |
| 订单状态     | status → 状态文本 | 包含 ✅   |
| 下单时间     | create_time       | 包含 ✅   |
| 支付时间     | pay_time          | 包含 ✅   |
| 成交时间     | deal_time         | 包含 ✅   |
| 订单备注     | remark            | 不导出 ❌ |

**Q4: 订单明细（order_item）是否需要导出？**

- A. 只导出订单主表，不导出明细
- B. 单 Sheet 模式：每个订单一行，订单明细以"商品名×数量"拼接字符串放在一列
- C. 双 Sheet 模式：Sheet1=订单主表，Sheet2=订单明细（每行一个 item，通过订单编号关联） ✅
- D. 合并模式：一个订单占多行（每个 item 占一行），主表字段在第一行，后续行为空

**Q5: 退款相关字段是否需要导出？**

- A. 不导出（退款有独立的退款管理模块）
- B. 仅导出退款状态
- C. 导出完整退款信息（退款类型、退款金额、退款原因、退款状态、退款申请时间、退款处理时间） ✅

## 3. 导出格式与样式

**Q6: Excel 列宽和样式？**

- A. 使用 EasyExcel 默认样式（自动列宽、无特殊格式） ✅
- B. 自定义列宽、表头加粗居中、金额列右对齐、日期列格式化

**Q7: 文件名格式？**

- A. 固定名称，如 `订单导出.xlsx`
- B. 带时间戳，如 `订单导出_20260605_143021.xlsx` ✅
- C. 带筛选条件摘要，如 `订单导出_待发货_20260605.xlsx`

## 4. 前端交互

**Q8: 导出按钮位置？**

- A. 放在搜索栏右侧（与"搜索""重置"按钮同行）
- B. 放在表格上方操作区（与产品管理的导出按钮位置一致）
- C. 放在表格右上角工具栏区域 ✅

参考：产品管理页面（`Front/admin/src/views/product/index.vue`）已有完整的导出交互实现，建议复用相同交互模式。

**Q9: 导出过程中的交互？**

- A. 点击后直接下载，无提示
- B. 点击后显示 loading 状态，完成后自动下载 ✅
- C. 点击后显示"正在导出，请稍候…"提示，完成后弹窗提醒

**Q10: 导出失败时如何处理？**

- A. 静默失败，控制台报错
- B. Element Plus Message 错误提示
- C. 弹窗提示错误详情并给出建议 ✅

## 5. 后端实现

**Q11: 是否复用现有查询逻辑？**

- A. 复用 `AdminOrderController` 的列表查询 Service 方法，传入相同筛选条件 ✅
- B. 单独编写导出专用查询（可优化为不分页、联表一次查出）

**Q12: 大数据量导出策略？**

- A. 一次性查询全部数据写入 Excel（适用于数据量小的场景） ✅
- B. 使用 EasyExcel 的分页查询 + 分批写入（适用于大数据量，避免 OOM）
